# R6 Lobby · 今晚开黑吗？

一个可自行部署的小队集结看板：今晚谁来、几点到、谁随时待命，一眼看清。

## 功能

- 跨访客共享「来 / 不来 / 未定」状态、队员昵称与预计到场时间。
- 两步时间选择器：09:00–23:00，每 15 分钟一档（最后一档 23:00），也可选「任意时间」，卡片显示「随时待命」。
- 来的人按具体时间升序排列，任意时间放在具体时间之后；图钉置顶仅影响当前浏览器，不改共享名单。
- 添加、改名、删除队员；手机紧凑布局；超过五人可展开。
- PWA 清单、添加到主屏幕指引和 service worker；不缓存 API。
- 可选的服务端 ntfy 留言转发，通知目标不进入前端。

应用界面目前为中文，仓库文档为中英文。它不是游戏客户端、匹配系统、在线侦测器，也未对接 Ubisoft／腾讯游戏接口。

## 从一起开黑出发的小设计

- **常用时段在前。** 小队通常傍晚、晚上玩，所以 17–23 点先显示并高亮，白天时间放到后面。
- **不让长菜单拖慢选择。** 先选小时、再选 15 分钟档，最后一档 23:00。
- **随时能来，不必编个时间。** 选「任意时间」后卡片显示「随时待命」，与具体时间明确区分。
- **把常一起玩的队友固定在眼前。** 图钉只影响自己的浏览器，不替别人改共享排序。
- **先看五人，其余展开。** 名单长时依然好扫读，也不隐藏其他队友的入口。
- **状态不仅靠颜色。** 来、不来、未定各有符号和文字，不必只辨颜色。
- **高频操作突出，低频操作收好。** 加入语音是主按钮；改名和删除收进铅笔，删除再确认。
- **手机上一行看清。** 姓名、紧凑时间选择器和状态操作放在同一行，长名字省略而不是挤乱布局。

## 本地启动

需要 Python **3.10+**。服务端仅使用标准库，不必安装 npm 或 pip 依赖。

```sh
python3 server.py
# 浏览器打开 http://127.0.0.1:8090/
```

初始名单为空，可在界面添加。数据写入被 Git 忽略的 `data/people.json`。配置通过环境变量传入，程序**不会自动读取 `.env`**：

```sh
export R6_HOST=127.0.0.1
export R6_PORT=8090
export R6_DATA_FILE=./data/people.json
# 可选：私下配置，不要把真实值写进提交
# export R6_NTFY_TOPIC=...
python3 server.py
```

部署前在 `web/index.html` 配好「加入语音」的链接；源码默认的 `#voice` 有意保持未配置。未配置通知目标时，留言会显示转发错误。真实 topic／token、名单及部署配置不得提交。

## 部署与信任边界

在回环服务前配置 HTTPS 反向代理，部署于域名根路径；页面使用绝对的 `/api/...`、manifest 和 worker 路径。主屏幕安装能力取决于系统及 HTTPS；离线页面外壳无法读取或保存共享名单。

**没有账号、登录鉴权或逐个队员权限控制。** 能访问页面的人可以替换整个名单、修改别人的姓名／状态；启用通知后也能发送留言。仅适合明确允许共同编辑的可信小群体，或由反向代理增加访问控制。未保护的部署不是私人空间。

写入采用原子 JSON 替换，但不是多人合并：并发操作可能相互覆盖，最后写入者生效。当前客户端在页面加载时读取，不提供实时推送更新。留言没有服务端频率限制，公开部署可能遭遇垃圾消息或消耗通知额度；请求大小与字段限制不能替代防滥用。通知响应只说明转发被接受，不代表手机已展示。

## 代码与数据

- `web/`：可移植前端、图标、manifest 和 worker。
- `server.py`：静态页面、`/api/people` 共享存储及 `/api/note` 转发。
- `docs/demo-roster.json`：虚构截图数据，不会自动加载。
- `tests/`：隔离 HTTP 测试及前端回归测试。

本快照把部署版前后端适配为一个本地服务，不包含线上基础设施、凭据、个人名单、备份或内部部署历史，也不修改运行中的个人看板。
